Вас вівтає додадоток з декодування VIN коду автомобіля. Додаток написан на React
з використанням зборщика VITE.

Використані бібліотеки:

- axios;
- Formik;
- nanoid;
- react-hot-toast;
- react-router-dom;
- yup;

Короткий опис додатку

На першій сторінці Home ви можете ввести в поле вводу свій VIN код автомобіля
(код повинен бути довжиной не більше/менше 17 букв латиского алфавіту та цифр,
приміняється валідація на кількість знаків та використання символів). Нажавши
кнопку Check VIN Ви отримаєете відповід у формі списка о всій доступній
інформації об автомобілі. До того ж змерігаються 3 останні пошуки і можливо
використату повторно любий з попередніх.

На другій сторінці наведена інформація щодо опису всих параметрів автомобіля.
Кожет з параметрів кликабелен. При клику ви будете перенесні на нову сторінку
для більш детального ознайоилення з описом
